レビューから本体へ反映

どのPCからでも、ブラウザーだけでコード・仕様の差分確認と、本体へ取り込むPRを作れます。PCへのGitやNode.jsのインストールは不要です。

本体への書き込み権限があるGitHubアカウントでログインしてください。このサイトの閲覧パスワードと、GitHubの書き込み権限は別です。

1. レビュー側に変更を保存

コードや仕様をS7-Reviewへコミットします。Web編集でも、普段の開発PCからのpushでも使えます。ブラウザー内のメモは、修正をコード・仕様へ反映してからコミットしてください。

ReviewをWebで編集保存された変更を確認

2. 差分と動作を確認・PRを作成

次の画面で Run workflow を押します。Branchは main、review_refは通常 main。まずmode check で確認し、反映する場合はmode pr で実行してください。

本体への反映を実行（GitHub）

本体の最新コードと3方向マージし、ビルド・検証後に専用ブランチとPRを作ります。競合や検証失敗があれば停止し、実行結果に表示します。

3. PRをマージして本体へ反映

実行結果のPRを開き、変更を確認して Merge pull request。本体mainへ反映され、公開は本体の設定に従って更新されます。

本体の反映PRを確認

GitHubの設定でPR自動作成が禁止されている場合、実行結果の比較リンクから Create pull request を押せます。

反映対象：共有ソース・画像/音源・恒久仕様・検証・依存ファイルのレビュー側差分。Vercel配信・認証・運用設定・引き継ぎログは移植しません。サイト内にはGitHubトークンを保存しません。本体mainへの直接上書きは行いません。
