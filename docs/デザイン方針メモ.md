これまでの指示と、そこから読み取れた判断基準をまとめたもの。
制作中に出た「なぜそうしたか」を残しておいて、次に同じ迷いをしないための覚書。

最終更新：2026-09-15

## 0. 貫いている原則

この5つが、個別の指示のほとんどを説明する。迷ったらここに戻る。

### ① 塊で押さない。量は分散させて出す

> 「ボムのエフェクトがぼやけていてダサいです。中央に1つだけの拡大使用はやめてその分量を出してください」

ぼかした大きな図形をひとつ拡大する演出は、**派手ではなく雑に見える**。
同じ「量」を出すなら、小さくて輪郭のはっきりしたものを数で散らす。

- 中央1枚の放射グラデーション → 撤去
- 49マスそれぞれを叩く明滅へ置き換え
- 虹の粒も「中心から噴き上げる」→「画面ぜんたいに配って短く弾ける」へ

`filter: blur()` は見た目の理由でも負荷の理由でも使わない。
にじみが要るときは**塗り（放射グラデーション）で作る**。一度描いたものを使い回せる。

### ② 速い演出には緩急と溜めを入れる

> 「アニメーションがちょっと速すぎて目で追いにくいです」
> 「シュパーンの前に400msの溜めを作ってください」

速さそのものは正義ではない。**読ませたい一瞬だけ粘らせる**。

- 獲得ワイプ：0〜22%で一気に中央へ → 22〜68%はほぼ静止 → 68〜100%で抜ける
- 発動：復色600ms → **400ms完全に止める** → シュパーン

音と絵が頭から重なると、どちらも印象に残らない。間を空けて順に立てる。

### ③ 演出は「何が起きたか」を伝えるためにある

> 「ここがボムで消えた領域、ということを強調しながら」

派手さは目的ではなく、情報を伝えるための手段。

- 消える範囲の明滅は、**メが乗っていない空きマスも含める**。歯抜けだと「範囲」が読めない
- 弾けたあとも320ms明滅を引っぱる。消えた結果を見せ切ってから通常へ戻る
- メはマスと逆相で光らせる。同相だと面ごと光るだけで目地が消え、のっぺりする

### ④ 軽さは制約ではなく前提

> 「とにかく軽い処理で最大限派手にアレンジしてください」

要素を増やさずに派手にする。動かすのは `transform` / `opacity` / `background-color` に寄せる。

- 光沢は要素を足さず `::after` 1枚で足りる
- 粒は数がそのまま負荷になる（実測：58個→40個でフレームレートが3割改善）
- 上限の目安は**同時40個**。49マス全部に粒を付けると300個になるので、**12マスに間引く**
- 1字ずつ色を送るなら、`animation-delay` を順にずらすだけでよい

### ⑤ 文字はできるだけ画面から減らす

> 「私は文字をなるべくなくしたいということをそろそろわかってくださいね」（2026-09-25）

**新しく画面に何かを足すときは、まず文字を使わずに伝えられないかを考える。**
案内・促し・状態の表示は、アイコン、動き、色、音で伝えるのが基本。
文字を置くのは、それ以外ではどうしても伝わらないときだけ。
一度この原則を見落として、起動時のサイコロに「タップしてサイコロをふる」と
文字を出してしまい、指摘されて 👆 のアイコンに差し替えた。

- タイトルロゴは画像に焼き込み、**テキストのタイトルは置かない**
- タグラインは削除
- 虹ボムの所持数は**アイコンのみ**。「虹ボム」の文字も個数の数字も出さない
- スマホではスコア段より下を全部消す
- 起動時のサイコロは、文字ではなく **👆 がトントンと叩く動き**でタップを促す
- 読み上げ用の説明（`aria-label`）は画面に出ないので残してよい

## 呼び名の決まり

- 連続消去の呼び名は **「チェイン」** に統一する。サイカの日本語セリフもカタカナの「チェイン」。英語表示は「CHAIN / chain」、2メンの名前は「チェイン目」。

- サイノメ同士でつくる技（スーパー1／スラッシュ3／スクウェア4／ストレイト6）は **「ひっさつメ」** と呼ぶ
- **「ボム」と呼ぶのは虹ボムとニコニコボムの2つだけ**
- チュートリアルでは略さない。書き出しは「ひっさつメの○○を教えるよ！」。遊んでいる最中の掛け声（スパ1！など）は短くてよい

- 敵「ダメ」は「ダーメ」に改称

## 1. サイノメ（ブロック）

| 項目 | 決定 |
|---|---|
| 色 | **明度を低く、彩度を高く**。パステルは却下 |
| 1・6 | ピンク `#fc6dac` |
| 2・5 | パープル `#8b46d2` |
| 3・4 | グリーン `#43ae39` |
| ニコニコメ | `#241a30` |
| 1/3/4/6 のメ | **白い円のみ。フチ線なし** |
| 2/5 のメ | `#330066`。黒ではなく、**暗いが彩度のあるパープル** |
| 角丸 | 26% |
| ハイライト | **芯（白の最も明るい点）は無し**。ほのかなグラデーションの質感だけ |

### 経緯として残しておくこと

- ハイライトの芯は一度入れたが、**メと同色に見えて逆に読みにくくなった**ので撤去した。
  「クッキリさせる」目的でハイライトを足すのは、メの視認性とトレードオフになる。
- 配色の再検討でピンクを `#FE97BF` → `#F8749F` → `#E44987` と動かしたが、
  **最終的にパープルとグリーンは元の色に戻した**。3色まとめて動かすと全体の関係が崩れる。
- 好みの方向は**ファビコン `fab01.png` の色みが基準**。「やや濃くて重量感のある」色。

## 2. 盤面

- マスは**青みがかったグレー**。タイル同士は**明度僅差**
- **クリアランス（隙間）はゼロ**。`gap: 0` で敷き詰め、`nth-child(even)` の市松で切る
- 盤面：7列 × 14段。危険領域は上から7段目より上

| 変数 | 値 |
|---|---|
| `--bg` | `#e9edf4` |
| `--board-bg` | `#9fabbd` |
| `--cell` | `#b4bfcf` |
| `--cell-alt` | `#a9b5c7` |

**注意：`.board-panel` に `z-index` を付けてはいけない。**
スタッキングコンテキストができて、中の `position: fixed`（タイトル画面）が閉じ込められる。

## 3. タイトル画面

- 絵を**全画面**に敷く（`object-fit: cover`）
- ロゴは画像に焼き込み済み。**テキストのタイトルは出さない**
- **キャラクターに文字やボタンをかぶせない**。操作は下段にまとめ、絵の主役を空ける
- 言語ボタン：グレー背景・白文字・小さく横長・横並び。スタートの**上**
- スタート：サイコロ型の角丸四角。中央下
- 説明ボタン：スタートの右。押すと縦スクロールのヘルプ（JA/ENタブは上）
- 虹ボムの所持数：**3つの円スロットが虹色で埋まる図のみ**。文字は一切なし

### やってはいけないこと

- **上部のぼかし帯**（絵の上に敷いた半透明の band）
- **周囲が暗くなるビネットフィルター**

どちらも「絵を見せる」という目的に逆行する。絵は絵のまま出す。

### 積み残し

タイトルロゴが 390×844 で左右 33〜42px 切れている。
ロゴが画像幅の 1.9%〜99.9% を使い切っているため、`cover` だと必ず欠ける。
**絵の側に余白を持たせて再生成するか**の判断が未了。

## 4. ゲーム中のUI

- 一時停止：3行目に「タイトル画面へ」
- サウンドアイコンは**絵文字に統一**。`🎶`（全部鳴る）/ `🎵`（BGMなし）/ `🔇`（無音）
  - **音符の数＝音の量**という読み方。`🔊`/`🔉` は18pxで見分けがつかないので却下
  - `♪` `♫`（U+266A/U+266B）は絵文字ではない（Extended_Pictographic ではない）ので使えない
- 「2525」バナーは削除
- 虹ボムの所持数は**盤面に出さない**

### スマホ（900px以下）

**スコア段より下は全部不要。** `.right-hud` ごと非表示。

消えるもの：NEXT／遊び方／ベスト記録／タッチボタン（←↓↻落）
残るもの：盤面／サイカ／スコア段（一時停止 `❚❚` と音 `🎶` はここ）

操作は盤面のスワイプで足りる。遊び方はタイトルの説明ボタン、記録はゲームオーバー画面に出る。

## 5. エフェクト

### フィーバー

- 背景に7色の円。**グリーンとスカイブルーを重ねて入れ**、寒色側の出番を増やす
  （`BURST_COLORS` をそのまま使うと暖色に寄る）
- 数は40個。**これ以上増やすと背景なのに主張しはじめて盤面が見づらくなる**
- `filter: blur` は使わない（phoneセッションでのコマ落ち対策として除去済み）

### ニコニコボム

- 円は**常に真円**（`vmax` で保証）。縦長・横長にしない
- 黒い粒は**縁に貼りつき、マスクの内側へ入らない**
  - 親（円）に対する `%` で置く。円が縮めば粒も一緒に引き寄せられる
  - 「親の半径ぶん外」で置くと、縮んだときに内側へ入り込む

### 虹ボム

| 段階 | 尺 | 内容 |
|---|---|---|
| 沈み | 600ms | ゲームオーバーの灰を途中まで |
| 「使う？」 | 3000ms | 正円の玉＋カラーサークルのメーター。BGMは半分 |
| 復色 | 600ms | **上から下へ**。12段階 |
| 溜め | 400ms | 完全に止める |
| 破裂 | 820ms | シュパーン＋メの飛散＋虹の粒36個 |
| 引っぱり | 320ms | 消えた範囲の明滅だけ残す |

- 消える7段は**49マスまるごと**白黒で明滅（110ms・`steps(1, end)` で中間色なし）
- 「使う？」の玉は**正円**。左上から差す白のグラデーションで光沢
- メーターは**白一色ではなくカラーサークルの塗り**。減る分はマスクで切る
- ボタン全体を**1秒周期で拡縮**（1.0 → 1.14 → 1.0）。いまにも弾けそうな呼吸
  - 芯だけ動かすと的の大きさが変わらず、切迫感が出ない
- 獲得ワイプ「虹ボムを1コかくとく！」
  - 1字ずつ7色が流れる（`animation-delay` を −70ms ずつずらす）
  - −13°の傾きで左下→右上へ横切る
  - 周囲に花火5つ。フィーバーの粒を400msに速回ししただけ

## 6. 音

すべて Web Audio でその場生成する（BGMのみ `HTMLAudioElement`）。
リミッターバス（`getSfxBus` → `createDynamicsCompressor`）を通す。

| 音 | 方針 |
|---|---|
| 設置音「トッ」 | 着地から**20ms以内**に鳴らす。ただし**着地後のスライド猶予は変えない** |
| 回転音「プリュン」 | 静かでかわいく。主張させない |
| ボムのロック音「テュルルルルッ」 | **技ごとに音程と波形を変える**（spa1 880Hz三角／sla3 659Hz矩形／squ4 587Hz矩形／str6 494Hz三角） |
| 虹ボム破裂「シュパーン！」 | **息を溜めてから割る2段構え**。シュ＝ノイズを500→6000Hzへ駆け上げ、パーン＝低音の芯＋ハイパスのノイズ＋上へ抜ける明るい和音 |

- BGMは**起動時のサイコロで出た目**に合わせて、1〜6の6セットから選ぶ
  - **タイトルと本編は必ず同じ目で揃える。**曲が変わったことを遊ぶ前に伝えたいのと、途中で世界が入れ替わらないようにするため
  - 1番だけファイル名に番号が付かない（2〜6を後から足したので既存名を温存した）
- BGMは**曲ごとの音量を実測で揃える**（RMS比較。タイトル vs 本編 = 0.0dB、フィーバー vs 本編 = 0.3dB）
- 虹ボムの「使う？」中は**BGMだけ半分**に絞る。効果音は絞らない

## 7. サイカ（案内役）

- 表情は**14種**。それぞれに感情を定義し、セリフを個別に持つ
- セリフの受け渡しは**番号＋テキスト**（`01-1：やっほー♪わたしはサイカ🎲`）
  → あとから「02-4 をこう直して」と指定できる形にしておく
- 波線は **`～`（U+FF5E 全角チルダ）に統一**。`〜`（U+301C）と混ぜない
- **フィーバー中は穏やかなコメントを出さない**。専用の行を持つ
- 表情の絵が似ていても問題ない。**表情とセリフを同時に見比べる人はいない**
  （似た絵を理由に統合を提案しないこと）

## 8. 技術の前提

- **SVGもcanvasも使わない。** 見た目はすべてCSS
  - サイコロ＝`border-radius: 26%` ＋グラデーション＋`box-shadow`
  - メ＝絶対配置の円（28% / 50% / 72%）
- React 19 + Vite 7 + TypeScript。実ファイルは `src/App.tsx` と `src/index.css` の2本
- `prefers-reduced-motion` は全演出で尊重する
  - **動きは止めるが、情報は殺さない**。飛翔を止めてもその場で光って消えるところは残す
- 色の判断は**測ってから決める**（CIELAB の L\*/C\*、WCAG コントラスト比）

## 10. 却下した案（蒸し返さないための記録）

| スマホでのNEXT表示 | 画面下で見切れる。無くても困らない |

## 2026-10-19 ヒョーケツメの寒色メタリック
本体を明るいライトブルー、7セグ数字をライトブルーに統一。導火線の火花は青・ライトブルー・白の細い集中線が外へ激しく拡散する。解凍後の待機は急拡大→頂点付近でゆっくり→急収縮→静かな復帰とし、最大125%。凍結中は1セル内で静止する。

氷のヒビは分岐した4パターンから2種を重ね、主線を太く枝を細くする。フチは上・左を明るく、下・右を暗くしたベベル。火花36本、導火線は頭部中央から伸ばす（2026-10-19）。
