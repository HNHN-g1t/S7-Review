# ヒッサツメ図鑑（開発確認用）

確認サイト `review.html` の第6タブ、または `skills.html` から開く。通常の本番ビルドには含めない。

## 新しい技を追加するとき

`src/skillCatalogue.ts` の `SKILL_ENTRIES` へ1件追加する。ID・正式名・分類・発動条件・効果・補足・7列の模式図を記載。実装済み技は `ability` に対応する習得能力を指定し、既存習得ステージへ接続。専用の模擬戦がある場合は `practiceUrl` を指定する。目次・一覧・模擬戦選択は自動で増える。

静止図は実ゲームのスクリーンショットではなく発動形と効果範囲の模式図。1〜6は出目、nはニコニコメ、bは起動したヒョーケツメ、*は効果方向/範囲、.は空マス。表示中はアニメーション停止。

既存の習得面を使う8項目は「お手本・模擬戦」。お手本を見て練習に進む。ヒョーケツボムは現在のヒョーケツメの時限爆発の呼称として掲載し、コイツメ・ダーメとの混成模擬戦へ接続。FEVERは強化状態として区別する。

確認用ゲームは実保存と分離し初期消音。模擬戦を閉じるとiframeを破棄。親のタブを切り替えたときも破棄するため、再表示時は最初から再開する。

検証：`node scripts/check-skill-catalogue.cjs`、`npm run build:gallery`。通常の `npm run build` にこのページを追加しない。
