## データと進行

- `src/story/wall1.ts` の WALL1 でタイトル・テーマ・座標・必須面 `requires`・選択面 `requiresAny`・目標数・敵配置を編集。通常セヴン目は同時グループ1回、チェインの各解決はそれぞれ加算。
- 旧ステージ0〜19の番号を維持し、新規面は内部ID20〜26。1-4でのみ既存のスーパー1講習を使用する。1-5/1-6は最初のスーパー1を作りやすい底段を用意。
- 未解放は鍵と不足条件を表示。マップ上の移動は解放済み道路だけを通る。0メンは独立した任意の練習で、本線の条件には含めない。
- マップ進捗のキーは `sainome-wall1-progress-v1`。不正な前提順の保存内容は読込時に除外し、門到達にはボス撃破を要求する。従来セーブとは分離。全進捗リセット操作は両方を消す。
- 地図から「順次進行版へ」、旧一覧から「マップ版へ」で切替。直接リンクは `/?story=map` / `/?story=linear`。
- フィーバーや他のひっさつメは今回未解放。既存モード側の解放順は変更しない。

## 選択ルートの意図

- 1-1 → 1-2／1-3のどちらか → 1-4（仙人）→ 1-5／1-6のどちらか → 1-7 → 門。ボスまで最短5面、選択の組合せは4通り。未選択面は後から挑戦でき、全7面の踏破も可能。
- 1-2は敵討伐に集中、1-3はセヴン目と敵討伐の複合。1-5はスーパー1の反復、1-6はスーパー1と敵討伐の複合。目標・敵・盤面は変更していない。
- どの経路でもセヴン目、コイツメ討伐、仙人の実演→練習2回→ミッション3回、習得後のスーパー1実践を経てボスへ進む。1-4とボス撃破は省略不可。
- `requires` は全件必須、`requiresAny` は指定時に1件以上必須。開始可否、鍵の案内、保存再読込は同じ定義を参照する。保存キーと形式は維持し、旧来の全必須ルートの進捗も読み込める。
- 今回は選択する課題の違いを作る最小修正。難しい近道の報酬や速度上の優位は追加しておらず、自然プレイでの難易度・ルート間の所要時間は未評価。
