# ドット絵プロンプト工房

参照画像の特徴を保ちながら、ドット絵の基準画像と連番アニメを作るための指示文を組み立てる独立ツール。確認サイトの先頭「ドット絵プロンプト工房」から同じブラウザタブで移動できる。ゲームの動作は変更しない。

## 開く

- 確認サイト `/review` の先頭「ドット絵プロンプト工房」を押す。工房右上の「確認サイト」から戻る。既存の5画面は確認サイト内のタブで切り替える。
- ローカル：`npm ci` → `npm run dev -- --host 127.0.0.1` → 表示されたポートの `/pixel-prompts.html`。
- Review 用：`npm run build:gallery` の `dist-gallery/pixel-prompts.html` に出力する。既存の Vercel 配信での経路は `/pixel-prompts`（cleanUrls）。サイト全体のパスワード保護がそのまま適用される。
- 通常の `npm run build` の `dist` には、ページと専用アセットを含めない。S7 本体へ移植しない。

## 使い方

1. 元の画像を選び、原寸1:1または全体表示で確認する。アップロードは任意だが、生成AIには元の画像を自分で添付する必要がある。
2. 8bit風（ファミコン風）・16bit風・32bit風・現代ドットから複数の画風を選ぶ。
3. 最大色数・基準幅/高さ・陰影段数を指定する。空欄は画風ごとの推奨値。輪郭・ディザリングは「自動」で画風に従う。上書きは全画風に共通で適用する。
4. 背景色、肌色／目の印象／顔の輪郭の忠実度、動作、コマ数、FPS、ループ、維持する特徴と自由記述を調整し、「まとめて作成」。動作を変更すると標準の詳細文も変わる（自分で書いた詳細文は保持する）。
5. 各画風の「基準の1枚」を画像生成AIへ渡し、元画像を添付して生成する。色数・寸法・顔・体格・ピクセルを確認、必要なら修正して確定する。
6. その画風の確定済み基準画像を再添付し、「連番アニメ」を使用する。全コマで同じパレット・キャンバス・座標系・顔・体格・衣装を固定する指示を含む。
7. 個別／全体のコピー、または UTF-8 BOM 付き `pixel-prompts.txt` の保存を使う。設定変更後は再作成するまでコピーと保存を無効にし、古い出力との取り違えを防ぐ。

8bit/16bit/32bit はハード世代のイメージであり、色数や基準寸法とは別の軸。実機のパレット、スプライト単位の色制限、メモリ制約を再現するモードではない。色数は陰影・輪郭・ディザリングを含めた不透明色全体の上限（透明は別枠、単色背景時はその色を含む）。陰影は素材・色系統ごとの基本色を含む最大段数で、総色数を優先する。

## 背景色と忠実度

背景は見本とHEX番号から1つ選ぶ。白が初期値で、透明も同じラジオグループ内のため単色と同時には選べない。

| 背景 | 色番号 |
| --- | --- |
| 白（初期値） | #FFFFFF |
| G255（純緑） | #00FF00 |
| グレー・明 | #C0C0C0 |
| グレー・中 | #808080 |
| グレー・暗 | #404040 |
| 透明 | アルファ透明 |

単色は背景色をパレットの固定1枠として確保し、全域不透明・指定HEXのままとする。例えば最大2色なら背景以外は最大1色。減色による背景色の近似置換、背景への影・グラデーション・ディザリングを禁止する指示を含む。透明では単色の指定や固定色枠を出さない。背景の選択は指示文にだけ適用し、参照画像のプレビューは加工・着色しない。

肌色・目の印象・顔の輪郭は、それぞれ独立した弱／中／強の単一選択（初期値は全て中）。ラジオ入力なのでキーボードの矢印でも変更できる。

| 忠実度 | 指示の考え方 |
| --- | --- |
| 弱 | 人物・キャラクターの特徴と同一性を残し、代表色や細部の簡略化を許容 |
| 中 | 主要な色調・形・比率と印象を優先し、細かな陰影や輪郭を整理 |
| 強 | 確認できる色調・形状・位置関係・比率を厳密に参照し、ドット化に必要な最小限の省略に限定 |

強でも総色数・寸法を優先し、元画像の全画素色をそのまま保持したり上限を超えて新色を追加する要求にはしない。肌はパレット内の近似色へ対応付け、色が不足する場合も背景の指定色を維持した上で顔の主要特徴を優先する。各指示は参照画像で該当部位を確認できる場合だけ適用し、未解析の肌色や形状を断定しない。人間の肌や目がない対象へ追加を要求しない。

これらの指定は全画風の「基準の1枚」「連番アニメ」に共通で反映され、その同じ文章を個別／全体コピーとテキスト保存に使用する。連番では確定済み基準画像を正本として、背景・パレット・顔と体格のコマ間固定も維持する。

## 端末内の処理と制約

画像は Blob URL を使ってこのページのメモリ内だけに読み込む。画像生成API、外部フォント、解析API、外部送信、localStorageへの保存は使わない。入力は再読み込みで消える。PNG/JPEG/WebP/GIF、20MB以下に対応。プレビューは元画像の表示だけで、ドット変換結果ではない。

プロンプトに画像データを埋め込まず、選んだ画像のファイル名を記載する。ユーザーが入力した固有特徴やファイル名は、コピー／保存するテキストに含まれる。クリップボードが使えない環境では選択済みテキストのダイアログを開き、手動コピーを案内する。

AI生成の忠実性、厳密なドット表現、パレット数、指定寸法、コマ間一致は保証しない。画像生成サービスごとの出力能力に応じた修正が必要。個別PNG連番が出せない場合は横1行のシートを指示するが、分割機能や実際の画像・アニメ生成は本ツールに含めない。

## 検証

`npm run build:gallery` → `npm run build` → `node scripts/check-pixel-prompts.cjs`。白／中の初期値、背景6択×忠実度27通り＝162設定を全4画風の両プロンプト／テキスト出力で検証する。最大2色時の背景枠、透明との矛盾防止、強度ごとの文の違い、未確認の特徴を断定しない指示を含む。従来の共通上書き・参照関係・ループ・入力境界・gallery専用出力も確認する。既存タブと隔離は `node scripts/check-review-isolation.cjs`。

ブラウザではPC／390px幅で初期値、背景の排他選択と見本色、忠実度の独立性・矢印操作、全画風・両プロンプト、コピー実内容と保存ファイル、プレビューが加工されないことを確認する。従来の画像原寸・全体表示・不正画像・コピー拒否時・先頭タブからの往復も確認する。Vercel認証はローカルViteには適用されない。認証設定は変更しない。
