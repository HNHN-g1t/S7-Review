# サンザッパラナメ

図鑑と共通ゲーム模擬戦、ウォール8のストーリーに登場。

## ストーリー配置

| メン | 噴火間隔 | 最大排出数 | 同時の見張り |
|---|---|---|---|
| 8-3 初登場 | 4手 | 2体 | なし |
| 8-4 実践 | 4手 | 3体 | なし |
| 8-6 複合戦 | 3手 | 4体 | コイツメ1・ダーメ1 |
| 8-7 門前 | 2手 | 4体 | ダーメ2 |

8-1は35,000点、8-2は通常見張り4体、8-5はデタラメ2体（同時1体）、8-8は任意の40,000点稽古。噴火で生成した敵も全滅の対象。自然プレイによる難易度の調整は今後のフィードバックを受けて行う。

## 身体と弱点

- 下5・中3・上1セルの融合した岩山。面取りした外周と内側ベゼル。削れた外周に合わせ輪郭を再生成。
- 最下段中央に目が1つ。半目の瞳は正円をまぶたでクリップ、被弾時は閉じ目と白フラッシュ。
- 中央縦3セルは通常セヴン目のダメージを受けない。目に隣接して7を消しても撃破できない。
- 通常セヴン目は消去セルの上下左右に当たる外周セルを削る。
- スラ3・スト6・イチニサンダーの攻撃範囲が目のセルに重なると撃破。目を外した場合は命中した外周だけ削り、中央縦3セルは残す。

## 蓄熱と噴火

- 噴火時の身体は底面固定、横幅100％のまま。伸び上がる101〜116％区間（280〜340ms）にコイツメとダーメを排出。180msで縦80％へ溜め、360msで116％へ伸び、900msで100％へ戻る。図鑑・模擬戦共通の補間関数で描画する。

- 2〜4ターンに1回コイツメを噴火。2ターン1〜2体、3ターン3〜4体、4ターン5〜6体（量対応はデザイン案）。
- 青緑〜赤の縦グラデーションが蓄熱とともに赤へ。4ターンMAXは朱色〜R255。
- 黒い角張った火口は身体内、下部に赤い溶岩。
- コイツメを上空へ打ち上げて積み上がりの最上段へ降らせる。各個体の赤発光は着地後400msでフェード。
- 横ストライプと上昇粒。通常24粒、MAX40粒・速度と寿命3倍。
- サイカ「また出した！さんざっぱら出てくるね！」。

## 模擬戦

図鑑の模擬戦ボタン・相手選択から開く。他のエネミーと同じApp・7×14盤面・サイの落下/回転/設置/消去/連鎖・ひっさつメ成立・FEVER・一時停止・再戦を使用する。旧命中テスト専用盤面は廃止。ストーリーでは上表のウォール8の配置で使用する。

- 最初は中央に5・3・1セル、下段中央に目。通常セヴン目は外周を削る。中央縦3セルは無敵。
- 実際に成立したスラ3・スト6・イチニサンダーが目に当たると撃破。ほかのひっさつメは外周削りのみ。
- 2〜4手で噴火。両種を混ぜるため発射数は最低2体（2〜6体）。排出開始は280ms、各個体12msずつずらして最大340msまで。各列の積み上がり最上段へ着地し、赤発光は400msフェード。
- 保存データは従来の模擬戦と同じメモリ保存で分離、初期音OFF。


## 着地の確定（2026-10-14）

- 飛翔の着地と同じフレームで実盤面へ小敵を置き、以後は通常の敵セルが表示を引き継ぐ。赤発光の400msフェードと演出の片付けで敵セルを消さない。
- 着地位置にサイがある場合は上書きして小敵に置き換える。同セルに後着した小敵は前の小敵を置換する。大型敵の身体は上書きしない。
- 生成数は実際に増えた敵数だけ数え、同セル置換・演出終了でMISSIONの撃破数を増やさない。連続噴火の各小敵は別ID・別groupを持つ。
- `npm run test:sanz` で着地後の保持、置換、連続手、カウント、中断・再開・再戦・退出を確認する。
