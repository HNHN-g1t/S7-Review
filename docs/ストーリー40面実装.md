# ストーリーマップ：40面実装・24面準備中

初版2026-10-05、単一目標化更新2026-10-06。ユーザーの補足「前の19メンが新しい40メンのイメージで、あと24メン分はこれから開発する」を採用。

## 今回の範囲

- 本線の配置枠は64。ウォール1〜5の各8面、計40面を実ゲームに接続した。
- ウォール6〜8の24枠は「準備中」。敵、技、目標を仮作成せず、起動もクリア保存もできない。
- 0メンのチュートリアル原っぱは64枠に含めない任意の練習。
- 40面目の5-8は旧19メンの総出演に相当する現在の到達点。最終ボスやサイノメ城の奪還完了ではない。
- 40は配置・プレイ可能な面の数。全40面のクリアは必須ではない。通常の分岐を選ぶと29面、3本の難関近道をすべて使うと最短26面。任意面はいつでも再訪できる。

## 分岐・近道・必修

- ウォール1は既存の4通り、最短5面の経路を維持。追加1-8は門を開く条件にしない。
- ウォール2は2-3のダーメ講習か2-4の実戦、2-6の敵課題か2-7の得点課題を選べる。
- ウォール3：3-2→3-3、または難関3-4。近道は高い盤面でダーメ3体を全滅させる。
- ウォール4：4-2→4-3、または難関4-4。近道は高い盤面でダーメ4体を全滅させる。
- ウォール5：5-3→5-4、または難関5-5。近道は高い足場のベラボウメ再戦。3・4の目の支援はあるが、通常路の敵より耐久力が大きい。
- 各近道は2面を1面に置き換える。必修の初回講習や門の守備隊は飛ばせない。技の習得と敵の初登場を共通路へ置く。
- 近道の所要時間・成功率の優位性は自然プレイで未測定。1面短縮はグラフ上で検証済み、体感難度は調整候補。

## 編集と実ゲーム接続

原本は `src/story/wall1.ts` の `CAMPAIGN_MISSIONS`。古い `public/story/world-draft.json` は参考試作であり、実ゲームの進行には使わない。

- `stage` は保存用の固定ID。旧0〜19はそのまま、マップは20〜59。将来枠60〜83は別定義。
- `sourceStage` は既存の教室・敵・連戦の処理を指定する。scriptの型・target・敵HPを保ち、マップ番号・保存IDと実行IDを分離。通常マップ面の実クリア判定は単一の敵全滅へ統一し、旧linear 20面の条件は変えない。
- `requires` は全件、`requiresAny` はどれか1件、`requiresAnyGroups` は各組から1件。技は `learns` と `requiresAbilities` による旗で管理。
- プレイ中の自分の講習技だけ一時解放し、クリア時に習得する。高い内部番号で未習得技が開くことはない。
- 通常面は `scoreTarget` のある6面なら得点到達だけ、それ以外は敵全滅だけ。通常面の `sevens`・`superOnes` は0、`bombTargets`・`nicoTarget`・`chainTarget` は設定しない。撃破面の `scoreTarget` も撤去。`objectives.ts` を目標文・汎用HUD・汎用達成判定で共有し、複合条件の再導入はテストで検出する。
- `seed` は既存練習の支援サイ、`boardRows` は通常課題の足場、`openingRows` は既存敵の再戦地形、`boostValues` は出やすい目。足場上の敵は支援サイを上書きしない。`enemies[].y` で絶対段を指定することも可能。
- 門の訪問、前のウォール、任意枝への再訪が可能。残る24枠は将来の地図として閲覧のみ。

## 保存と既存版

- 保存キー `sainome-wall1-progress-v1` と既存20〜26のIDを維持。旧Wall1のクリアと `gateReached` はそのまま読める。
- 追加の `reachedWalls` は任意。未保存でも前エリアのボスを倒していれば次へ進める。未開発の門フラグは除外。
- 読込は前提条件が整ったクリアを反復解決し、順不同・重複・不正IDや未開発IDを正規化。通常保存は旧順次進行のキーを書かない。
- `/?story=linear` と画面下の切替で従来20面へ戻れる。既存バックアップブランチも維持。
- 同じ旧処理を使う別マップ面／同じ面の再開始に対応し、非同期講習・敵処理・演出待ちを実行世代で分離。再開始前に作られた未発火の待ちや死亡後の片付けが、新しい盤面に戻らない。

### 未検証と制約

ローカルViteは起動できたが、提供ブラウザーの127.0.0.1接続は `ERR_BLOCKED_BY_CLIENT`、ローカルChromium起動はsocket権限制限で失敗。これらを迂回していない。スマホ幅の実描画・実機タップ・音声・40面を自然に進める難易度／平均所要時間は未検証。Nodeハーネスの結果をブラウザーや自然プレイの確認とは扱わない。
