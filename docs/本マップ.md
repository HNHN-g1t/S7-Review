# 本マップ：画像を原本にしたマップUI

## 確認先
レビューサイトの最上段「本マップ」、単独ページ /book-map.html（Vercelでは /book-map）。
画像原本はユーザー提供のwall1_.pngをpublic/maps/wall1.pngとしてそのまま保存。

## 仕様と分離
- ウォール1の既存8メンとチュートリアル0を画像内の広場へ配置。城は出口の装飾でメンを追加しない。
- タイトル・テーマ・前提条件はsrc/story/wall1.tsを参照。解放判定も既存wallUnlockedを共用。
- 初期の確認状態は0/1-1クリア、1-2選択。実際のゲーム進行には接続しない。
- メンを選ぶと番号/タイトル/説明/ミッション/解放条件と挑戦ボタンを表示。挑戦は既存の保存分離済みreview-gameをiframeで起動。
- 狭い画面では選択内容を画面下へ固定。従来のマップはそのまま残す。

## 確認→調整→ゲーム反映
1. 本マップを開いて見た目・メン選択を確認。
2. 「レビュー・配置調整」で全開放やクリア表示を試す。
3. 「マーカーをドラッグ」で座標を調整。座標は画像左上からのパーセント。
4. 修正メモを書き「配置と修正メモを一括コピー」でチャットへ貼る。
5. 合意した座標をsrc/bookMap/model.tsのDEFAULT_LAYOUTへ反映。
6. デザイン確定後にゲーム本体へ画像/配置/選択UIを移植する。本編の進行/解放/保存と接続して検証。

レビューの座標/メモだけ専用localStorageキーへ保存。本編の保存キーは読まない/書かない。コピーは座標とメモのみで認証情報を含めない。
今回の変更はS7-Reviewのみ。SAINOME-SEVEN本体のマップや配信設定は変更しない。
