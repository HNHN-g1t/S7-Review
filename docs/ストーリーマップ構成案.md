# サイノメ城奪還・ストーリーマップ構成案

2026-10-04 / design/story-map-area1-20261004 / main 未統合

## 確定した方向

サイリアン達に占領されたサイノメ城を取り戻す。草原から城門、城内へ攻める。
一方通行ではなくエリア内の行き先を選ぶ。未解放ステージは鍵を表示し、必要なフラグを揃えてボスへ挑む。
分岐にさまざまなミッションを置き、近道には難しい面を用意する。最終ボスまで約64面を目安とする。
敵・達成目標スコアなどを、後から面単位で調整しやすくする。

## 仮構成：8エリア × 8面 = 64面

以下のエリア分け・旗の種類・配分は提案。ユーザーが確定した固有名や難易度ではない。

| エリア | 面 | 舞台・役割 |
| --- | --- | --- |
| 1 | 1–8 | サイノメ草原：分岐と旗集めを覚える |
| 2 | 9–16 | 城下への街道：道の選択と複数条件 |
| 3 | 17–24 | 城下町：敵の組み合わせ |
| 4 | 25–32 | 外壁と城門：城への突破戦 |
| 5 | 33–40 | 城内・前庭：城内攻略の入口 |
| 6 | 41–48 | 城内・回廊：寄り道と難路 |
| 7 | 49–56 | 城内・上層：終盤の複合ミッション |
| 8 | 57–64 | 王座への道：最後の旗と最終ボス |

64面は寄り道・近道・8体分のボス枠を含む配置数で、全クリア必須の面数ではない。
現在の共通骨格では通常ルート6面/エリア、近道3面/エリア。全域で48面/24面だが、これは接続検証の値であり最終プレイ尺ではない。
2エリア以降の地形・分岐は同じ検証用骨格の仮配置。64面の実ゲームや固有ギミックが完成したわけではない。

## 最初の草原：旗で解放する

- 入口クリアでスコアルート・チェインルート・難しい近道を解放。
- スコアルートから東の見張り台へ。討伐で東の旗を得る。
- チェインルートから西の守りへ。生存ミッションで西の旗を得る。その先に任意の寄り道。
- 難しい近道は、スコア＋討伐＋短いターン制限。1面で東西両方の旗を得る。
- 東西の旗を揃えると草原ボス解放。近道でも旗の条件は飛ばさない。
- ボスを倒すと次エリアの入口解放。試作画面は草原の1レイヤーのみで次エリアへの移動は未接続。
- 鍵をタップした場合は条件のみ提示し、移動や挑戦を行わない。達成済み地点は再訪可能。

近道が常に最適にならないよう、通常ルートは練習しながら安定して進める難度にする。
寄り道の報酬は未確定。永続強化・アイテムなどの新システムは今回導入していない。

## 編集するデータ

原本は `public/story/world-draft.json`。プレビュー内の埋め込みデータを直接編集しない。

| フィールド | 調整内容 |
| --- | --- |
| `id` / `number` / `areaId` | 固定ID、表示番号、所属エリア。並べ替えにID変更は不要 |
| `role` | entry / mission / flag / optional / shortcut / boss |
| `mapPosition` / `artKey` | マップ座標、将来の画像キー（現在 null） |
| `unlock.allCleared` | すべてクリア必須の前提ステージ |
| `unlock.anyCleared` | いずれか1つをクリア（空なら条件なし） |
| `unlock.allFlags` | 必要なフラグすべて。エリア別IDで混同しない |
| `rewards.flags` | クリアで得る旗。近道には両方を指定 |
| `objectives.mode` / `items` | all または any。スコア・チェイン・討伐・生存ターン・7の成立回数 |
| `enemies` | 敵種、出現数、HP上書き、出現間隔（ターン） |
| `turnLimit` / `timeLimitSeconds` | 制限。null はこのデータによる上書きなし |
| `difficulty` | 難度の意図と調整状態。ラベルだけでゲーム難度は変わらない |
| `areas[].edges` | マップ上の道。解放条件とは別に管理 |

プレビュー再生成：`node scripts/build-story-map-preview.mjs`。
生成物 `public/story-map-preview.html` は単体でも開ける。

数値・敵配置は全て `unbalanced-draft`。実ゲームへ接続して検証するまで正式なレベルデザインとして扱わない。
最終ボスは `finalBossPlaceholder` で未定と明記。存在しない敵を実装済みとして呼び出さない。
敵IDは試作用。ゲーム側とつなぐときに既存の敵識別子へ明示的に対応づける。

## 実ゲームとの接続で残っている作業

- 実プレイ結果で目標 all / any を判定し、成功時だけクリア・報酬を付与するアダプター。
- 敵配置・HP・出現間隔・ターン/時間制限を実ゲームへ反映するアダプター。
- 既存の直線型ストーリーセーブとの対応、移行方針。試作は専用キーのみを使用。
- 2エリア以降の固有分岐・地形・ミッション、最終ボスの選定と調整。
- 失敗時の再挑戦、全体マップやエリア間移動、正式アート。

本試作の「クリアを試す」は条件判定を省いたUI確認用操作。本番へそのまま接続しない。
