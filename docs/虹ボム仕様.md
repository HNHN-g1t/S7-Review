# サイノメ・セヴン ／ 虹ボム仕様・課金方針

決定日：2026-09-11（更新：2026-09-11 第2版）
ステータス：Q1〜Q8 まで確定。Q9（音）以降が未着手。

## 前提（このドキュメント単体で読めるように）

- 7列 × 14段の落ち物パズル。となり合う目の合計が 7 で消える。
- **危険領域** … 上から7段目より上にメが積まれた状態。スコア2倍／ニコニコメ出現／サイカが焦る。
- **ゲームオーバー** … 最上段にメが乗る（左端2マス・右端2マスは判定除外）。
  演出は 1600ms かけて上から灰に沈め、その後 400ms で文字がバラバラに出現。
- 既存ボム4種：スパ1／スラ3／スク4／スト6。優先順位は ニコニコボム > 各種ボム > セヴン消し。
- 現状の保存データは localStorage の2つのみ（言語設定・ベストスコア上位5件）。
- Web版が Vercel で公開中。Bundle ID は com.hnhn.sainome7（iOSのみ・Android対象外）。

## 0. 課金方針（前提）

| 項目 | 決定 |
|---|---|
| 収益モデル | 無料DL ＋ 非消耗型IAP 1本（フルアンロック ¥490 程度） |
| 課金で変わるもの | 見た目と記録だけ |
| ゲームバランス | 一切売らない |
| 広告 | 入れない |
| サーバー | 立てない。ランキングは Game Center |
| Web版 | 無料の本体のまま。課金は載せない |

**非消耗型IAPを選ぶ決定的な理由**
購入履歴を Apple 側が持つため、復元は `restorePurchases` だけで済む。
アカウントもサーバーも要らない＝**現在の localStorage だけの構造を壊さずに課金できる唯一の形**。

**フルアンロックの中身（現時点）**
- 虹ボムの演出バリエーション
- 虹ボムボタンの画像スキン ← プレイ中で最も凝視される1点
- UIスキン
- ロング版BGM
- サイカの虹ボム専用表情（Q8で追加候補として発生）

**コスト**
- Apple Developer Program … 年 $99（約¥15,000）
- 手数料 … Small Business Program 申請で 15%
- ¥490 → 手取り約¥416 → 年会費回収に約36本

**売上の前提を誤らないための注記**
「機能は全部無料、売るのは見た目だけ」は**買う理由が弱い**モデル。
¥490を払う最大の動機は「好きだから／応援したいから」で、スキンとBGMはその口実。
狙うべきは「100人に1人が課金」ではなく「熱心な20人が払う」ほう。

**リスク（未対応）**
- WKWebView ラッパーは審査 4.2（Minimum Functionality）でリジェクトされ得る。
  初回提出時点で Game Center・IAP・オフライン動作・ハプティクスを載せて回避する。

## 1. 虹ボム — 確定仕様

### 1-1. 位置づけ
- ラストボム改め **「虹ボム」**。
- **全プレイヤーに無料開放**。課金の向こう側には置かない。
  （リテンション装置なので、まだ払っていない人に届かないと意味がない）
- 既存4種（スパ1／スラ3／スク4／スト6）は目の数字に紐づく命名体系。
  虹ボムはそこから外れた別系統＝「別枠」であることが名前で伝わる。

### 1-2. 効果
- **上から9段のメを全消去**（危険領域の7段＋その下の2段）。
  - 当初は危険領域の7段だけだったが、救済としての手応えを上げるため2段広げた（2026-09-23）。
  - 危険状態に入る高さ（上から7段）は変えていない。広げたのは消す範囲だけ。
- 下5段の地形は残る。仕込みが無駄にならない。
- **スコアに加算しない／支給用カウンターにも加算しない。**
  → 加算すると自己増殖して、一度3個貯めたプレイが永久に終わらなくなる。

> ニコニコメ＝危険領域に「入ると出てくる」もの
> 虹ボム　　＝危険領域から「出してくれる」もの
> 同じ領域の入口と出口が向かい合う構造。

### 1-3. 支給ルール
- 根拠は **プレイ内の消去マス数**。時計には一切依存しない（チート不能・ランキング1本で済む）。
- 支給は **プレイ中にリアルタイム**。稼いだ1個をそのプレイで使える。
- ストックは **持ち越しあり／上限3個**。
- 上限に達している間は、ワイプを出さずカウンターだけ貯める。

### 1-4. カウンターは2本に分ける
| 名称 | 用途 | 表示場所 | 挙動 |
|---|---|---|---|
| 履歴消去ブロック数 | 記録・モチベーション | **タイトル画面のみ** | 増えるだけ |
| 支給用カウンター | 虹ボムの支給判定 | （内部） | 支給ごとに閾値分を**減算** |

分けないと、下手なプレイを繰り返すだけで貯まる＝雑なプレイが通貨になる。

### 1-5. 閾値（未確定）
- **暫定 150〜200マス。**
- 100マス案は検算の結果、供給過多の可能性が高い（下記）。
- **カウンターを先に実装して実測してから確定する。**

概算（コード未参照のため推定）：
| プレイ | スコア | 推定マス数 | 100マス＝1個なら |
|---|---|---|---|
| 低調時 | 30,000 | 150〜300 | 1〜3個 |
| 最高記録 | 510,000 | 1,500〜3,000 | 15〜30個 |

このゲームは倍率が掛け算で重なるため、**スコアは指数的・マス数は線形**に伸びる。
閾値だけでは両端を同時に満たせないので、上限3個のキャップが必須。

目標：低調時に0〜1個、好調時に上限3個へ届く。

### 1-6. 保存データ（localStorage が 2 → 5 項目に増える）
| キー | 内容 | 備考 |
|---|---|---|
| （既存）言語設定 | ja / en | — |
| （既存）ベストスコア | 上位5件 | — |
| 履歴消去ブロック数 | 生涯累計 | タイトル画面に表示 |
| 虹ボム所持数 | 0〜3 | プレイをまたいで持ち越す |
| 支給用カウンター | 0〜閾値 | 支給ごとに減算 |

**既存ユーザーへの配慮**：3項目とも、値が無い場合は 0 で開始する。
移行処理は不要だが、初回起動時に「虹ボム0個・カウンター0」で始まることを確認する。

## 2. 獲得演出

- 閾値到達の瞬間に **ワイプウィンドウ**。ボムアイコン＋「虹ボム〇コ獲得！」
- 出すのは **消去と落下が完全に終わり、次のブロックが出る直前の隙間だけ**。
  連鎖の途中には絶対に出さない。
- 尺は **600〜800ms**（既存の400ms／1200msの文法内）。
- **ニコニコメの1200ms演出とは絶対に重ねない。** 重なったら次の隙間まで待たせる。

## 3. 発動シークエンス（確定）

```
最上段にメが乗る＝ゲームオーバー判定
  ↓
沈み演出を 600ms だけ走らせる（上3段ほどが灰に沈む）← 「あ、死んだ」を体感させる
  ↓
停止・暗転
  ↓
「使う？」＋点滅する虹ボムボタン
  ・ボタン画像は差し替え可能な構造にしておく（＝課金スキンの受け皿）
  ・ボタンの周囲を巻くタイムゲージ … 3.000秒ジャスト
  ↓
YES         → 灰が下から復色 → 7段目より上を全消去 → 続行（ストック −1）
NO / 時間切れ → 残り1000msの沈みを再開 → 「ゲームオーバー」の文字
```

- **タイムアウト時は虹ボムを消費しない。**
- 割り込み位置を600msにする理由：危険領域がちょうど沈みかけたところで止まり、
  YESで消える範囲と灰に沈む範囲が視覚的に重なる。
- 3秒ゲージは、意思決定を「判断」ではなく「反射」に変える装置として採用。
  （制限時間なし案は撤回。合理的にはNOを選ぶ理由がないため、判断ではなく反射にしたほうが目的に合う）

| 場面 | 表情 | 通常時 | フィーバー中 |
|---|---|---|---|
| ① 獲得ワイプ | ボム成立 | saika-03 | saika-11 |

また、ニコニコボムですら専用表情も技名バナーも持っていない。
→ **専用表情はフルアンロックの中身に回す。**

## 6. 設計の背骨（迷ったらここに戻る）

1. **機能は配って、見え方を売る。** バランスは非売品。
2. **中毒装置は無料側に置く。** 課金の壁の向こうに隠すと、一番効かせたい相手に届かない。
3. **時計に依存しない。** サーバーを持たない以上、時間を根拠にすると必ず壊れる。
4. **「もうだめだ」を殺さない。** 救済が日常化した瞬間に、救済の価値は消える。
5. **新しい概念を増やさない。** 危険領域・ボム成立・既存5表情の再利用で足りる。

## 7. 検討の過程で却下した案（蒸し返さないための記録）

| 案 | 却下理由 |
|---|---|
| ラストボムを課金で有効化 | 中毒装置が無課金層に届かない。ランキングも課金者の順位表になる |
| 3時間に1発の時間支給 | 端末時計を進めれば無限。サーバーが無い以上、検知できるのは巻き戻しだけ |
| 100マス＝1個 | 好調プレイで15〜30個。そのプレイが終わらなくなり「もうだめだ」が消える |
| 虹ボムで盤面を全消去 | 積み上げた地形と仕込みが消え、助かったのに手応えが下がる |
| 上からN段を固定で消す | 下が詰まっていると助からない。「使ったのに死んだ」は後味が悪い |
| Yes/Noに制限時間を設けない | NOを選ぶ合理性が無く選択が形骸化する。3秒ゲージで反射に変えた |
| サイカに虹ボム専用表情を追加 | フィーバー版も必要になり5→7種。既存5種で足りる（課金側へ回す） |
| 広告（リワードでコンティニュー） | 積み上げゲーの緊張とスコアの意味を壊す。DAU数百では収益も見合わない |
| アイテム課金・通貨・スタミナ | 残高を端末外で守る必要があり、認証＋DB＋復旧対応が恒常コストになる |
