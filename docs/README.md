# 資料置き場

ゲーム本体のコードとは別に、検討の記録を残しておく場所。
`public/` の外にあるので、ここに置いたものはビルドにも配信にも含まれない。

ファイルはブラウザでそのまま開ける単体のHTMLにしてある。
開発サーバーを立てなくても読めるよう、外部の読み込みは持たせない。

| ファイル | 内容 |
|---|---|
| `ストーリー40面実装.md` | 40実装面と24準備中枠、全ミッション、接続・保存・検証 |
| `saika-lines.html` | サイカのセリフと表情の一覧。顔つきで確認できる |
| `saika-lines.tsv` | 上と同じ内容を編集できる形にしたもの。**書き換えるのはこちら** |
| `block-colors-2026-09-07.html` | ブロック配色の Before → After 比較。指定色 `#FE97BF` / `#9F5AF5` / `#49B932` を当てた見本と、明度・彩度・目のコントラストの実測値 |
| `デザイン方針メモ.md` | これまでの指示と判断基準のまとめ。**次に作るときはまずこれを読む** |

## アンチクショウメ（登場指定用・本体未統合）

仕様と動く見本を共有済み。ゲーム側で登場を指定されたときに接続し、通常出現には自動追加しない。詳細は[アンチクショウメ仕様](anchikushoume/DESIGN.md)を参照。
