# 通常ミッションの単一目標化

2026-10-06 22:39 JST。対象はマップの全40面。旧linear 20面・チュートリアル0メン・将来24枠は変更対象外。

## 採用した仕様

- 習得10面を除いた通常30面では、敵全滅または得点到達のどちらか1つだけをクリア条件にする。
- 撃破24面の目標は「サイリアンをぜんぶ倒せ！」。技発動・チェイン・得点の追加条件は撤去する。
- 得点6面の目標は「N,NNN点とれ！」。得点だけで判定する。
- 既習技を試す面は教室ではない。支援用seed・出目補助・足場を維持し、特定技の使用を強制しない。
- 1-2の分割出現、1-6/1-7の増援、4-5/5-8の全波、4-8の未出現分、5-6/5-8の生成小敵も全滅に含める。登場前や波の切り替わりの一瞬に敵が0になってもクリアしない。
- 敵の配置・HP・攻撃を受けるルール・大型敵の最後の目の倒し方、地形、分岐、解放条件、保存ID・保存形式は維持する。
- 追加UI指定：マップ上の各面・0メンのミッション説明文は表示しない。面番号・タイトル・挑戦ボタン・解除ヒントは保持。本番の4秒帯と開発用進行表では単一目標を使う。
- 全40面の目標と開始案内は [文面照合表](mission-banner-20261006.md) に記載。

## 得点6面

| 面 | 得点 | 判断理由 |
|---|---:|---|
| 1-1 | 1,000 | 序盤の短い得点課題。基本セヴン消しは1回200点なので約5回分。旧3回条件とは等価ではなく、実得点は連鎖や同時消去で変わる |
| 1-5 | 2,000 | 従来の序盤スコア課題と同程度。スーパー1の出目支援は維持 |
| 2-7 | 4,000 | 元の4,000点を維持し、スクウェア4の回数条件だけ撤去 |
| 3-2 | 4,000 | 直前の2-7と同程度。ストレイト6の支援seedは維持 |
| 4-2 | 12,000 | ユーザーが以前に明示した希望値を反映 |
| 5-1 | 6,000 | 第5章入口の得点課題。4-2より低い値は、支援盤面と特殊出現なしの構成を踏まえた設計判断。4種類すべての発動条件は撤去し、自然プレイ難度は未検証 |

新しいしきい値の自然プレイによる所要時間・成功率は別途評価する。得点設定は従来の技回数と数学的に等価であるとは扱わない。

講習のお手本・練習・本番の区別、1-4の3回目通常出目、2-2の高さ救済、習得フラグは保持。4-1には元からFEVER発動回数の条件がない。

## 実装上の境界

- `src/story/wall1.ts` の通常面は `sevens`・`superOnes` を0にし、`chainTarget`・`nicoTarget`・`bombTargets` を撤去。撃破面の `scoreTarget` も削除。6つの得点面だけが `scoreTarget` を持つ。
- `theme` は通常面の単一目標へ同期。表示の原本は `missionObjectiveText` とし、古いthemeで文面を戻さない。
- `missionGoalFor` は `sourceStage` の既存script型・targetを保持する。敵の出現や教室分岐で使うため、すべてを汎用wall型へ置換しない。
- `storyObjectiveText(goal, mission)` と `missionObjectiveGuide(mission)` は通常マップ面なら単一目標を優先。旧linearでの呼出しは元の文面を保持する。
- 汎用 `wallObjectiveParts`・`wallObjectiveProgress`・`wallObjectiveMet` は通常面で得点または敵数の1単位を使う。得点到達には敵全滅を重ねない。敵面では点数や技回数を重ねない。
- script付き通常面の残敵・登場待ち・波はApp側で扱う。旧linearの特殊勝利条件からマップの全滅条件を分離し、生成小敵の残留を許さない。
- お手本と操作練習の帯は「特訓中！」だけに固定。本番のmissionフェーズに入ってから、タイトルを先に4秒ずつ目標文と交互表示。通常面の敵登場中はタイトルを保ち、操作開始から交互表示する。pause/resume・やり直し・面移動時の解除、スマホの帯余白は維持する。
