# アンチクショウメとイチニサンダーの演出・操作更新

更新：2026-10-08 08:36 JST（Codex）
対象：既存ウォール6・ゲーム本体・開発専用のキャラクター図鑑と模擬戦。

## 実装

- 目の移動と成長でCanvasの模様・触手時計を作り直さない。1.5秒ごとの目移動を450msの上辺・左右辺の経路で見せる。最下段は角も含め禁止、1段だけの身体は上辺を使う。
- 身体の原点が成長で変わる場合は目の座標を補正。同じ補間座標から描画と命中セルを決定する。
- 吸収はデタラメと同じ白い三重リングを使用し、760msの演出が終わってから食べたサイを身体へ置き換える。
- ペンキは旧2手に1回から4手に1回へ。発射音／320ms飛行／着弾音／260ms拡がり／3〜5秒滞在／420ms消失。停止中は進めず、再戦・退出では破棄する。
- 雷が目に命中した瞬間から黄色点滅と被弾表情。目以外の身体接触・完全な空振りでは撃破しない。目へのひっさつメ1回で撃破する既存仕様は維持。
- 「サン」を残して同じ行へ「ダー！」を足す。各0.7秒、通常3列ランダム非隣接・FEVER5列・専用雷サウンドチャネルは維持。
- 1→2→3を連続してなぞる間、サイより上に白い軌跡を表示。途中で離すと入力と軌跡を消し、1から再試行可能。順序違い・pointercancel・lost capture・pause・新しいゲーム・対象サイ差替えも破棄。中断操作を回転や即落下へ誤変換しない。
- 図鑑に現在の目移動・黄色被弾・ペンキの一連の演出。模擬戦は6種となり、アンチは1・2・3が揃った盤面から開始。実セーブ隔離と本番ビルド除外を維持。
- 今回のペンキ・雷サウンドは停止／ミュート／画面非表示／再戦／破棄で残響を止める。

## 検証

- `npm run test:story`、`npm run test:audio`：既存回帰。
- `npm run test:anchi`：目の全サイズ・全経路・成長原点補正・Canvas時計／非表示復帰、実Appの指操作、音声ソース接続／解除、実App雷の目命中／身体だけ／空振り／FEVER、吸収・半頻度ペンキ・停止／再戦、6-4のアンチ＋2体デタラメ。
- `node scripts/check-review-isolation.cjs`：確認用iframeの保存隔離とタブ破棄。
- `npm run typecheck`、通常／図鑑の両ビルド。通常ビルドに図鑑・review・模擬戦のHTMLが含まれないことを確認。

命中・入力・タイマー・描画命令・音声ノードの検証は、実コードを使った決定的なVM／Canvas mock検証。スマホ実機の操作感、実ブラウザーの描画、音の聴感、難易度はこの検証に含めない。大型BGMは変更しておらず既存公開資産を維持する。
