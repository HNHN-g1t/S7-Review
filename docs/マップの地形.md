# マップの地形（2026-10-11）

ウォールごとの地形は `src/story/wallTerrain.ts`、面の位置は `src/story/wall1.ts` の x・y。
いまは図形だけのラフ。絵に差し替えるときも、この構造（スタート・門・障害物・道の回り方）を下敷きにする。

共通の決まり：スタート（最初の面）は下段、門は上段。道はまん中の障害物を回り込む。
道どうしは交差せず、池・建物・城壁は横切らず、川は橋の上でだけ渡る（`scripts/check-wall-terrain.mjs` で確認。`SOFT=1` で問題を全部並べる）。

| ウォール | 地形 | スタート → 門 | 道の回り方 |
|---|---|---|---|
| 1 草原 | 噴水の池・木立・花 | 左下（0メンの島のとなり）→ 左上 | 池の左を上がる道と、池の下から右へ回り込んで上を通る道 |
| 2 街道 | 横に流れる川・橋の上の宿場（2-5）・丘 | 左下 → 右上 | どの道も川の上の宿場に集まり、そこから上へ分かれる |
| 3 城下 | 家並み | 右下 → 左上 | 家のあいだをジグザグに抜ける |
| 4 外壁 | 堀と城壁（右側だけ切れ目）・塔 | 左下 → 左上 | 城壁の切れ目（右）まで回り込み、壁の内側を左へ戻る |
| 5 前庭 | 中央の噴水広場・生け垣・花壇 | 下段まん中 → 上段まん中 | 噴水広場の左右を回る |
| 6 回廊 | 中庭・柱 | 右下 → 右上 | 中庭のまわりをコの字に回る |

道の曲がり角は `bends`（キーは「小さいステージ番号-大きいステージ番号」）。サイカのコマも曲がり角をたどって歩く。
