# エンジョーメ：図鑑デザイン案

2026-10-19 ユーザー指定。まずS7-Reviewのヒッサツメ図鑑へ追加、本編へは未実装。

## 形
縦2セルの投下爆弾。朱色〜赤の金属本体、明るいオレンジのベベル、尾翼と尖った先端、炎のマークを持つ。外周の壁で2セルまとめて封印。

## 発動手順
1. 隣接セヴン目消しで囲いの壁を除去。
2. タップ可能状態になり、ボムをタップすると上空へ上昇・待機。
3. 次のサイ落下で発動し、高速で最下段へ着弾。
4. 下からピラミッド状の全対象セルにある敵とボムを破壊。

通常は下から7・5・3・1（16セル）、FEVERは9・7・5・3・1（25セル）。

## 今回の確認方法と範囲
ヒッサツメ図鑑の末尾のエンジョーメで、一連のデモ再生または壁解除→ボムタップ→次のサイ落下を手動で試す。通常/FEVER切替と大きい表示に対応。非表示時はタイマーとCSSアニメを停止。無音、保存なし。
9列の模式盤で範囲を描く。実際の7列盤の端での範囲処理、登場頻度、壁の耐久値、他の技との優先順、実戦の判定は未実装。今回は検討用デモであり既存ゲームエンジンの模擬戦ではない。
